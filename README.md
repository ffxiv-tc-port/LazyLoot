# LazyLoot

[LazyLoot](https://github.com/PunishXIV/LazyLoot) 的台服移植版，快速且一致地處理擲骰，支援全自動擲骰與依道具/任務自訂規則。

## 功能

- **快速擲骰**：`/lazy need`、`/lazy greed`、`/lazy pass` 對目前戰利品一次套用需求/貪婪/放棄（需求失敗自動改貪婪，貪婪失敗自動改放棄）
- **FULF 全自動擲骰**：啟用後依需求/貪婪/放棄模式自動擲骰，並可設定最短/最長延遲避免動作過快
- **全域規則篩選**：依裝備等級、非本職業裝備、已解鎖收藏（坐騎、寵物、坐騎裝甲、九宮幻卡、管弦樂琴樂譜、褪色複製品、表情動作、髮型）、裝備升級判斷（低於目前職業等級/不是升級）、上繳大國防聯軍可換的軍票數低於下限等條件自動放棄；投影用道具永不放棄；每週次數限制任務內自動暫停擲骰
- **道具/任務個別規則**：可針對特定道具 ID 或特定任務設定需求/貪婪/放棄/不處理，並套用優先於全域規則；支援清單匯出/匯入
- **診斷模式**：於聊天欄印出每次判斷「為何放棄」等原因，方便排查規則設定
- **輸出與提示**：擲骰結果可印至聊天欄，或以彈出提示顯示
- **伺服器資訊列（DTR）**：顯示目前 FULF 模式，左鍵／右鍵依正反順序切換模式，Ctrl＋點擊開關設定視窗
- **指令**：`/lazyloot`／`/lazy`（開啟設定視窗）、`/lazy test item <道具ID或名稱>`（測試特定道具會被如何處理）、`/lazy diag [on|off]`（切換擲骰診斷記錄）、`/fulf [on|off]`、`/fulf need|greed|pass`

## 台服版的修改

- 修正台服上全自動擲骰從不觸發（擲骰提示在台服是另一種聊天類型）。
- 擲骰提示與週限次提示的比對改走與資料表同一套文字解析，句子帶特殊格式時也比得中。
- 擲骰診斷記錄改為預設關閉。
- 擲骰用語對齊台服官方（需求／貪婪／放棄）；介面與伺服器資訊列繁體中文化。
